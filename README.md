# RetainAI
### AI-Powered Customer Churn Prediction & Retention Assistant

RetainAI is a machine learning project designed to predict customer churn, identify customers who may leave a business, and provide intelligent retention recommendations.

The project combines customer data analysis, machine learning, explainable AI, and an AI-powered assistant to support better customer retention decisions.

## Project Objectives

- Predict whether a customer is likely to leave.
- Estimate customer churn probability.
- Identify important factors influencing churn.
- Explain individual predictions using Explainable AI.
- Recommend customer retention strategies.
- Provide an interactive analytics dashboard.

## Technology Stack

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- SHAP
- FastAPI
- React.js
- MongoDB

## Dataset

IBM Telco Customer Churn Dataset.

The dataset contains customer information, services, contract details, billing information, and churn status.
